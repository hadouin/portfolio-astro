# Recommendation portraits

Drop the portrait for each recommender here, named after the `avatar`
field in `src/i18n/data.ts`:

- `hippolyte-bach.jpg`
- `raphael-cournault.jpg`
- `valentin-ricard.jpg`

Square crops are best. They're rendered at 48px in a circle, so anything
above ~200px is plenty. `png`, `jpg`, `webp` and `avif` are all picked up.

A missing file is not an error: the card falls back to an initials monogram.
